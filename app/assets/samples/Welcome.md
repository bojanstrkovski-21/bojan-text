# Welcome to Bojan Text

A fast, good-looking editor with a **live Markdown preview**, a **color-code colorizer** and support for **Sublime Text packages**.

## What's new

- Colors like `#5ab0f6`, `rgb(255 122 89)` and `hsl(150, 60%, 55%)` light up as you type
- Alt+Click a color to change it with a picker
- Markdown preview: side by side (Alt+M) or in your browser (Alt+B)
- [x] Themes follow your color scheme
- [ ] Try *Preferences ▸ Theme & Appearance*

## Shortcuts

| Action           | Keys           |
|------------------|----------------|
| Command palette  | Ctrl+Shift+P   |
| Goto anything    | Ctrl+P         |
| Preview split    | Alt+M          |

```rust
fn main() {
    let accent = "#ffb454";
    println!("Hello from Bojan Text {accent}");
}
```

> Tip: language servers (rust-analyzer, pyright…) are picked up automatically when installed.
